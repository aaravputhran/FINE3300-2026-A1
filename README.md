**4. Comparison of My Code and the AI Code**
Both programs use the same Bank of Canada file, pick out the FXAUSDCAD column, and produce identical conversions: they multiply by the rate for USD to CAD and divide by it for CAD to USD. The differences are in the process. 
My version (ExchangeRates.py) maps almost directly onto the Bond class file that we did in class and reads the file line by line with open() and split(), loops through the header row to find the USD/CAD column, and takes the rate from the last row. It keeps the file name and rate as private members (double underscore), exposes them through get_rate() and get_date(), and prints the date of the rate so the user knows which day's rate is being used. It also puts the code under an if __name__ == "__main__" block and builds the full path to the CSV, so it runs no matter which folder VS Code is opened in. 
The AI version (ExchangeRatesAI.py), generated by GPT-6, is shorter and utilizes Python's built-in csv.DictReader, which looks columns up by name instead of by position, and a with statement that closes the file automatically. 
It is also more defensive: it skips blank rate values rather than assuming the last row is complete, raises an error if no rate is found, and validates the currency codes inside convert() with a try/except around the call. Since the assignment says inputs can be assumed valid, that extra checking is not required, but it would make the code safer in practice. 
On the other hand, the AI version stores its data in public attributes, runs its main program at the top level (so it would execute if the file were imported), depends on the CSV being in the current working directory, and does not show the date of the rate. Most importantly for this assignment, its output omits the dollar sign and thousands separator that the results section requires, which my version includes. 
Overall, the AI produced working, robust code quickly, but it needed checking against the specific requirements, which reinforced that vibe-coded output still has to be reviewed by the person submitting it.
